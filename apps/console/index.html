CLI Setup

Point the agent CLI at this local API. Local mode uses the local owner workspace.

npm install -g @inf-monkeys-tech/monkeys-memory-cli
monkeys-memory config set api-url http://localhost:3000
export MONKEYS_MEMORY_TOKEN=local
monkeys-memory retrieve --repo my-repo --path src/index.ts --task feature
monkeys-memory memory-evaluate --repo my-repo --rule-id returned_item_id --outcome helpful --adopted true --evidence "npm test passed"
